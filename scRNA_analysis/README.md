# scRNA-seq analysis and manuscript figure generation

## Overview
This directory contains all analysis code required to reporduce all findings and figures from the manuscript. The starting point only requires this code and a Seurat R object which is available from GEO (Accession: [GSE296507](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE296507)) .

## R

  Primary analysis with the code to generate all the main figures and most supplementary figures

## supplemental_analysis

  Code for remaining supplementary figures and analysis

## **Note**
See [MATLAB](https://github.com/cohmathonc/CML.BC.scRNA-manuscript/tree/main/MATLAB) for modeling code and figures.
